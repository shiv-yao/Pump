# Installable Skills Bundle

Included plugins:
- calculator
- market_data
- trading_signals
- alpha_scanner
- trading_api
- gnn_wallet_alpha
- solana_onchain_alpha
- polymarket_arb
- fund_brain

## Install by copying
Copy the plugin folders into your platform's `plugins/` directory.

## Install by URL
After pushing these folders to GitHub:
`/install PLUGIN_NAME https://raw.githubusercontent.com/<user>/<repo>/main/plugins/PLUGIN_NAME`

## Required env vars for trading_api
- TRADING_API_BASE
- TRADING_API_KEY (optional)

## Notes
Some plugins are connectors and alpha layers. They are not a promise of profit.
